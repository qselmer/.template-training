# Repository naming standard

Use short, complete English words. Do not encode the repository type in the repository name when the `type-*` topic already provides that classification.

Preferred pattern:

```text
[resource]-[scope]-[purpose]
```

Examples:

- `git-github-teaching`
- `r-data-teaching`
- `anchovy-growth-workflow`
- `pelagic-mse-template`
- `tuna-cpue-paper`
- `ocean-monitoring-app`

The repository type is stored separately as one canonical topic, e.g. `type-training`, `type-workflow`, `type-paper`, or `type-template`.
