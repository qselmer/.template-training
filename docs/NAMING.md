# Repository naming

Use short, descriptive, lowercase names separated by hyphens.

Preferred pattern:

```text
[resource]-[scope]-[purpose]
```

Use complete words when possible. Do not repeat the repository type in the name when it is already clear from the GitHub `type-*` topic.

Examples:

```text
git-github-teaching
stock-assessment-teaching
spatial-models-workshop
mse-training
r-programming-teaching
```

Avoid ambiguous names such as `course2`, `training-new`, `test`, or unexplained initials.
