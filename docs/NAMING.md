# Repository naming

Use short, descriptive, lowercase names separated by hyphens. Do not abbreviate words merely to reduce length.

Preferred pattern:

```text
[resource]-[scope]-[purpose]
```

The repository type is stored separately as a GitHub `type-*` topic and does not need to be repeated when the name is already clear.

Examples:

```text
git-github-teaching
stock-assessment-teaching
spatial-models-workshop
mse-training
r-programming-teaching
```

Avoid ambiguous legacy names such as `course2`, `training_new`, `test`, or initials that are not obvious to an external reader.
